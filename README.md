# למען v2 — חזרה על שאלות ותשובות

בנייה מחדש ונקייה של אפליקציית "למען" (deepfocus-zone), לפי העקרונות הבאים:

## עקרונות הארכיטקטורה
- **Local-first, בלי Supabase (שלב 1):** כל הנתונים ב-IndexedDB דרך Dexie. כל הגישה לנתונים עוברת דרך `src/db/` בלבד — כשיתווסף סנכרון ענן, הוא ייכנס כמודול נפרד שם.
- **בלי Service Worker / PWA:** נמנע במכוון (מקור לבאגים של גרסאות ישנות). יתווסף רק אם יידרש בעתיד.
- **בלי פולינג:** אין setInterval-ים מפוזרים. ה-UI מתעדכן ריאקטיבית דרך `useLiveQuery` של Dexie. הטיימר היחיד הוא שעון המבחן, והוא נהרס כשהמבחן נגמר.
- **קבצים קטנים:** כל מסך בקובץ משלו, לוגיקה ב-feature folders.

## מבנה
```
src/
  db/            שכבת הנתונים היחידה (Dexie) + ייבוא מאגר הש"ס
  features/study טיפוסים + מנוע SRS (SM-2 / FSRS) — הועתק נקי מהפרויקט המקורי
  components/    Layout (סרגל ניווט RTL, החלפת ערכת נושא)
  pages/         בית, חזרה, מבחן, שאלות, מסכתות, סטטיסטיקות, הגדרות
public/data/     full_shas_qna_report.json — מאגר השו"ת (נטען בעת ייבוא, לא ב-bundle)
```

## הרצה
```bash
npm install
npm run dev            # http://localhost:5010
npm run build          # בניית web
npm run desktop:dev    # אפליקציית דסקטופ (Tauri, דורש Rust)
npm run desktop:build  # מתקין NSIS ל-Windows (src-tauri/target/release/bundle)

# אנדרואיד (דורש Android SDK + JDK):
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug   # APK ב-app/build/outputs/apk/debug
```

## מה יש
- המאגר המלא: 22,699 שאלות (אמריקאיות + כרטיסיות) עם כל עץ הקטגוריות המקורי
- חזרה חכמה (SRS): SM-2 או FSRS, תור לפי דחיפות/קושי/דיוק; תרגול לפי סדר/מסכת
- מבחן מתוזמן עם ציון; חפיסות אישיות; יעדים עם מדדי התקדמות
- לוח חזרות עברי (hebcal) עם ממתינות/בוצעו לכל יום
- סייר קטגוריות בסגנון תיקיות עם ספירות
- בניית שאלות: חיפוש עמום, עריכה, ייצוא Word/Excel
- סטטיסטיקות, גיבוי/שחזור JSON, שתי ערכות נושא
- אפליקציית דסקטופ (Tauri) ואפליקציית אנדרואיד (Capacitor)
- סנכרון ענן בין מכשירים (src/db/sync.ts): תמונת-מצב דחוסה בפרויקט Supabase
  ייעודי "lemaan", ממוענת בקוד סנכרון אקראי; משיכה מחליפה את הנתונים המקומיים
